# LLM from Scratch

A learning project to understand how Large Language Models (LLMs) are built from the ground up.

## Overview

This project explores the fundamentals of building Language Models, including:
- Data loading and preprocessing
- Tokenization
- Model architecture
- Training and evaluation

## Project Structure

- `data_loader.py` - Script for loading and preprocessing text data
- `the-verdict.txt` - Sample text data for training

## Getting Started

### Prerequisites

- Python 3.8+
- Required libraries (to be added)

### Running the Data Loader

To load and preprocess the sample text data:

```bash
python data_loader.py
```

## Learning Goals

- Understand tokenization and text preprocessing
- Build a basic neural network for language modeling
- Implement forward and backward propagation
- Learn about attention mechanisms
